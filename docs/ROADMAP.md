# KEV Research Roadmap

## Current
Persistent local runtime with semantic classification, typed cognitive memory, reviewed lessons, challenger training, and rejection of non-improving candidates.

## Next — compositional cognition
Extract multiple typed frames from one utterance and bind exact values/provenance separately from semantic relations.

## Then — state-conditioned reasoning
Use explicit goals, constraints, observations, predictions, and evidence for planning and bounded tool selection.

## Then — closed measured learning loop
Task → observation → reviewed lesson → challenger → fresh evaluation → reject/qualify.

## Then — broader language
Improve semantic breadth with permission-compatible data or documented teacher distillation while preserving held-out vocabulary audits.

## Evidence standard
Increasingly general intelligence requires breadth, transfer, retention, calibration, robustness, reproducibility, and independent evaluation. Version numbers and lower training loss are not substitutes.
