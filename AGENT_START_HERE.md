# Start Here — KEV

You are entering the current KEV research workspace. Treat repository manifests, model hashes, audits, and receipts as source-of-truth evidence.

## Mission
Develop KEV into a local, persistent, teachable, evidence-grounded intelligence that can represent multiple goals, constraints, observations, predictions, memories, and verified tool results; reason over those structures; act through bounded adapters; learn from reviewed experience; and retain capability across updates.

Do not describe the current system as AGI or superintelligence.

## Invariants
- Never overwrite an incumbent checkpoint.
- Training completion is not promotion.
- Ordinary chat is not automatically truth or training data.
- Reviewed lessons are explicit and provenance-bearing.
- Once an audit influences a change, it becomes development evidence.
- Separate memory improvement from weight improvement.
- Never claim a tool ran without an execution receipt.
- Preserve raw failures and rejected candidates.

## Highest-priority experiment
Move from one semantic label per utterance to compositional cognitive frames: GOAL + CONSTRAINT + OBSERVATION + PREDICTION in one state update.
