# Security Policy

- Never commit API keys, tokens, private keys, private conversation state, session transcripts, or private reviewed lessons.
- Keep runtime state and ledgers local.
- A language-model response is not proof that a tool ran; tool claims require execution receipts.
- Learned models do not receive repository mutation or checkpoint activation authority by default.
- Never overwrite an incumbent checkpoint in place.

For vulnerabilities, use a GitHub security advisory when available rather than publishing secrets or exploit details in a public issue.
