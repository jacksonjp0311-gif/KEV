# Public Repository Snapshot

This repository is the GitHub-safe KEV source snapshot.

It intentionally excludes large model checkpoints, private/local runtime state, generated archives, caches, and historical binary artifacts. The architecture, current runtime source, human documentation, mathematics, AI-agent continuation contract, and checkpoint provenance are public here.

Large checkpoints should be distributed through a GitHub Release or Git LFS. Do not commit private session state or silently substitute different weights.
