# Contributing to KEV

KEV is experimental cognitive-runtime research. Preserve the distinction between measured capability and aspiration.

Before changing the system:
1. Read README.md and AI_AGENT_GUIDE.md.
2. Use fresh state for experiments.
3. Never overwrite an incumbent checkpoint.
4. Freeze evaluation data before scoring when a result is intended as fresh evidence.
5. Preserve raw failures and rejected challengers.

A strong PR states the hypothesis, changed files, evaluation protocol, before/after measurements, retention/regression results, and limitations. Training completion alone is not evidence of improvement.
