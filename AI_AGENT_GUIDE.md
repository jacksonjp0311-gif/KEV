## Operating contract
Preserve provenance and rejected candidates. Create challengers instead of overwriting incumbents. Separate memory recall, changed weights, deterministic execution, grounding, language generation, and verification. A gain in one category must not be reported as another.

## Current objective
Build compositional semantic frames so a single utterance can yield multiple typed state updates, then connect verified tool observations back into the same state.

## Claim boundary
KEV is experimental research software. Do not claim AGI or superintelligence without broad, independent evidence.
